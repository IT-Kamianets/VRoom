# VRoom — опис проєкту для дипломних робіт

VRoom — система для створення інтер’єрів квартир, яка поєднує AI-генерацію, 3D-редактор і VR (Meta Quest 3). Проєкт поділено на дві дипломні роботи, що з’єднуються через спільний формат опису сцени (scene JSON).

```
                     VROOM
          ┌────────────┴────────────┐
      3D ENGINE                VROOM LOGIC
     (Крістіна)                  (Аліна)
  Unity · Scene · Assets   Interior · Catalog · Project
  XR · Spatial             Design · Sync
          └────────────┬────────────┘
        ┌──────────────┼──────────────┐
    PC Unity        Quest VR      Mobile/Web
                       │
          ┌────────────┴────────────┐
       Firebase               AI / build123d
  збереження проєктів    генерація / зміна сцени
                              assets store
```

## Робота 1. Крістіна Олефіренко

**Тема:** Розробка кросплатформного 3D-клієнта для редагування віртуальних інтер’єрів у Unity з підтримкою PC та Meta Quest 3.

**Мета:** створити єдиний Unity-клієнт, у якому той самий проєкт квартири можна переглядати й редагувати на ПК (миша/клавіатура) та в шоломі Meta Quest 3 (контролери/руки).

**Об’єкт дослідження:** процес інтерактивного редагування тривимірних сцен інтер’єру на різних платформах.

**Предмет дослідження:** методи та програмні засоби побудови кросплатформного 3D/VR-редактора на рушії Unity.

### Завдання
1. Проаналізувати наявні 3D- та VR-редактори інтер’єру (Planner 5D, IKEA Kreativ, Arkio тощо), визначити вимоги.
2. Спроєктувати архітектуру клієнта з розділенням на сцену, інтерфейс, введення та дані.
3. Реалізувати редактор сцени: переміщення, обертання, масштабування, дублювання, видалення, прив’язка (snap) до стін, підлоги й поверхонь, Undo/Redo (патерн Command).
4. Реалізувати інтерфейс: Scene Tree, панель властивостей, каталог меблів, зміна матеріалів і кольорів.
5. Реалізувати VR-режим для Meta Quest 3 (OpenXR, XR Interaction Toolkit): захоплення та переміщення меблів руками, телепорт і плавне пересування, VR-панелі.
6. Створити єдиний шар введення, щоб ті самі команди працювали з мишею та з VR-контролерами.
7. Реалізувати побудову сцени зі scene JSON (від системи Аліни) і запис ручних змін назад.
8. Реалізувати збереження та синхронізацію проєктів через Firebase (Auth, Firestore, Storage).
9. Оптимізувати продуктивність для мобільного GPU Quest 3, протестувати на обох платформах.

### Орієнтовна структура пояснювальної записки
1. Аналіз предметної області та існуючих рішень.
2. Проєктування архітектури кросплатформного клієнта.
3. Реалізація редактора сцени та інтерфейсу (PC).
4. Реалізація VR-режиму та синхронізації.
5. Тестування, оптимізація та аналіз результатів.

### Технології
Unity 6 (URP), C#, OpenXR, XR Interaction Toolkit, Meta XR SDK, uGUI / UI Toolkit, Addressables, glTF/GLB-імпорт, Firebase SDK.

### Очікувані результати
- Windows-збірка редактора та APK для Meta Quest 3.
- Один проєкт, що відкривається на обох пристроях.
- Демонстраційна квартира з меблями.

## Робота 2. Аліна

**Тема:** Розробка інтелектуальної системи автоматичної генерації та зміни планування інтер’єру на основі правил розстановки та AI.

**Мета:** створити систему, яка за планом квартири автоматично формує коректну розстановку меблів і змінює її за командами користувача природною мовою.

**Об’єкт дослідження:** процес автоматизованого планування інтер’єру житлових приміщень.

**Предмет дослідження:** методи поєднання правил розстановки (constraint-based) і моделей штучного інтелекту для генерації та модифікації інтер’єру.

### Завдання
1. Проаналізувати методи автоматичної розстановки меблів (правила, оптимізація, генеративні моделі, LLM).
2. Сформувати модель даних: кімнати, стіни, прорізи (двері/вікна), функціональні зони, каталог моделей із характеристиками (розміри, категорія, стиль, ціна, посилання).
3. Розробити рушій правил розстановки: мінімальні проходи, неперекриття дверей і вікон, відсутність перетинів, орієнтація меблів (ліжко до стіни, диван навпроти ТВ тощо).
4. Розробити алгоритм генерації варіантів розстановки з урахуванням стилю та бюджету.
5. Інтегрувати AI (LLM) для розбору команд природною мовою («заміни диван на менший», «зроби більше вільного простору», «покажи три інші варіанти») у конкретні операції зі сценою з перевіркою правилами.
6. Реалізувати генерацію геометрії стін, прорізів і параметричних меблів за допомогою build123d.
7. Реалізувати експорт результату у scene JSON для Unity-клієнта та формування списку меблів із цінами.
8. Оцінити якість розстановки (дотримання правил, час генерації, оцінка користувачами).

### Орієнтовна структура пояснювальної записки
1. Аналіз методів автоматичного планування інтер’єру.
2. Модель даних і формалізація правил розстановки.
3. Алгоритм генерації та AI-модуль зміни сцени.
4. Програмна реалізація та інтеграція з клієнтом.
5. Експериментальна оцінка якості.

### Технології
Python, build123d, LLM API (з function calling / structured output), FastAPI або Firebase Cloud Functions, Firestore, JSON Schema.

### Очікувані результати
- Сервіс, що генерує scene JSON з плану та параметрів.
- Набір формалізованих правил розстановки.
- Обробка команд природною мовою зі зміною сцени.
- Метрики якості згенерованих інтер’єрів.

## Спільна частина

**Scene JSON** — контракт між роботами (спрощений приклад):

```json
{
  "room": { "w": 4.2, "l": 3.6, "h": 2.7 },
  "openings": [{ "type": "door", "wall": 0 }],
  "style": "modern",
  "items": [{ "id": "sofa_01", "catalog": "sofa-m", "pos": [1.2, 0, 0.4], "rot": 90 }]
}
```

| 4. Розширення | VR на Quest 3, синхронізація | AI-команди, варіанти, build123d |
| 5. Інтеграція | Тестування на пристроях | Оцінка якості розстановки |
